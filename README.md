# nerosaude.com.br

Site público do **NERO**, aplicativo de acompanhamento de saúde.

| Caminho | Endereço |
|---|---|
| `index.html` | `https://nerosaude.com.br` (redireciona para a política) |
| `privacidade/index.html` | `https://nerosaude.com.br/privacidade` |

HTML estático, sem dependências, com tema claro e escuro.

## Não edite a política aqui

A fonte é `docs/nero/publicacao/politica-de-privacidade.md`, no repositório do aplicativo. Este
repositório recebe o HTML **gerado** a partir dela (`npm run site` lá). Editar direto aqui faz as
duas versões divergirem, e a que vale juridicamente é a do app.

## Publicação

A Hostinger observa a branch `main` e publica sozinha a cada push.
